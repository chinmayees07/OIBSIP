FINAL NO-FETCH BMI CALCULATOR

This calculator performs BMI calculation directly in the browser. It does NOT use fetch(), so it cannot show a failed-to-fetch error.

EASIEST METHOD:
1. Extract this ZIP.
2. Double-click RUN-WEBSITE.bat.
3. If Node.js is installed, it opens http://localhost:5000.
4. If Node.js is not installed, it opens public/index.html and still works.

You may also double-click public/index.html directly. The calculator works offline.
